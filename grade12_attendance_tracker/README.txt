GRADE 12 ATTENDANCE TRACKER — VS CODE

WHAT YOU NEED
- Visual Studio Code
- A web browser (Chrome, Edge, Firefox, etc.)

HOW TO OPEN
1. Extract grade12_attendance_tracker.zip.
2. Open VS Code.
3. Click File > Open Folder.
4. Select the extracted folder named grade12_attendance_tracker.
5. Open index.html.
6. Right-click index.html and choose "Open with Live Server" if you have the Live Server extension.
   If you do not have Live Server, you can open index.html directly in your browser.

HOW TO USE
1. Enter the student number, full name, and section.
2. Click "+ Add student".
3. Choose the attendance date.
4. Set each student's status to Present, Absent, Late, or Not marked.
5. Click "Save attendance".
6. Click "Export CSV" to download a spreadsheet-friendly attendance record.

IMPORTANT
- This starter version saves data in the current browser using localStorage.
- It does not sync between devices or users.
- Clearing browser data may erase saved records, so export backups regularly.
- Use fictional sample data while testing. Keep student information private.
